# Offensive and Defensive Security Labs

A collection of hands-on cybersecurity exercises covering reconnaissance, vulnerability assessment, controlled exploitation, packet analysis, firewall configuration, intrusion detection, and ARP spoofing in virtual lab environments.

These labs are for **education and authorized testing only**. Use intentionally vulnerable systems that you own or have explicit permission to test. Keep attack exercises on an isolated virtual network; never scan, exploit, spoof, or capture traffic from networks or devices without authorization.

## Labs

| Lab | Topic | What you will practice |
|---|---|---|
| [Lab 1](./Lab1/readme.md) | Network discovery and vulnerability assessment | Check connectivity, enumerate services with Nmap, and review findings from a Nessus scan. |
| [Lab 2](./Lab2/readme.md) | Metasploit exploitation | Identify a vulnerable service on Metasploitable 2, use the Metasploit Framework, and verify controlled root access. |
| [Lab 3](./Lab3/README.md) | Network traffic analysis with Wireshark | Generate lab traffic and inspect FTP, Telnet, and HTTP traffic to understand the risks of unencrypted protocols. |
| [Lab 4](./Lab4/README.md) | Firewall and IDS setup | Configure firewall rules in pfSense, enable Snort, and review alerts generated by lab traffic. |
| [Lab 5](./Lab5/README.md) | ARP spoofing and HTTP analysis | Demonstrate ARP spoofing in an isolated virtual network and inspect HTTP traffic to a DVWA lab target. |
| [Lab 6](./Lab6/README.md) | Web application risk assessment | Use OWASP ZAP to scan DVWA and review findings against the OWASP Top 10. |
| [Lab 7](./Lab7/README.md) | OSINT reconnaissance | Use Google Dorking and Shodan to examine publicly available information and exposed services. |
| [Lab 8](./Lab8/README.md) | Work in progress | The experiment details and evidence have not yet been added to the repository. |
| [Lab 9](./Lab9/README.md) | Password guessing with Hydra | Test weak SSH credentials against Metasploitable 2 using controlled wordlists. |
| [Lab 10](./Lab10/README.md) | Phishing awareness simulation | Configure a Gophish campaign and review awareness metrics without collecting real credentials. |

Each completed lab README includes its objective, requirements or lab setup, procedure, results, and related screenshots.

## Lab environment

The exercises use virtual machines and tools such as:

- Kali Linux for security testing and traffic analysis
- Metasploitable 2 and DVWA as intentionally vulnerable practice targets
- VMware or VirtualBox with an isolated host-only or internal network
- Nmap, Metasploit Framework, Nessus, Wireshark, pfSense, and Snort

The exact machine addresses and setup may differ between labs. Follow the individual lab instructions and verify the target address and network isolation before running any commands.

## Getting started

1. Review the safety guidance and select a lab above.
2. Set up the required virtual machines on an isolated network.
3. Follow that lab's README and use only the target systems specified for the exercise.
4. Stop scans, captures, or spoofing processes when the exercise is complete, and restore any lab network settings you changed.
